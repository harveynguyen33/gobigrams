# Support

Thanks for using **Gobigrams** — diagrams drawn by a goblin with a grudge and a ruler.

- **How-to questions** → [GitHub Discussions](https://github.com/harveynguyen33/gobigrams/discussions)
- **Bugs and feature ideas** → [open an issue](https://github.com/harveynguyen33/gobigrams/issues) (bug and feature templates are provided — short answers are fine)
- **Found a security problem** → see [SECURITY.md](SECURITY.md), please don't open a public issue for it
- **In-app**: the *Feedback* link in Settings → About opens the issues page directly

When reporting a bug, a board export (Settings → Export → JSON) plus any red console errors (F12 → Console) make fixes much faster.
