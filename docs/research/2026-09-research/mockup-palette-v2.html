What changed from v1 (and why)
v1 gave each diagram type its own palette, which made the same element appear up to 4 times (Note ×4) and hid that Database / Container: database, Service / Component / Container: application / Software System are the same rectangle with a different name.

v2 model — the library is one list; every element carries a types[] array. The diagram type selects a filtered view of it:
FilterElementsWhat it is now
All34the whole library, badges show each type
Architecture10a filter over the one library
Flowchart12a filter
C412a filter — its own 11 C4 elements + the shared Note
Data model3a filter — Table + Note + Note (enum)
Mixed27its own curated set, NOT a filter
The only element shared between types is the generic Note (architecture + flowchart + C4). It is drawn once, badged ARCH FLOW C4 — that is the duplication fix.

Consequence for the spec — note, once in annotations, is now a shared element (all four types), and C4 ⊇ architecture's shapes means the C4 preset's palette is a derived union, not 11 hand-listed items.
