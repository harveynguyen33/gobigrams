Rules the kit enforces: every control shows hover (border → border-strong) and focus (border → acc + 3px acc-soft ring). Native selects get appearance:none + a chevron we draw, so Safari/Chrome/Windows look identical and all five themes work.

Scope: applies to Settings (select/input/switch/segmented/buttons) and the inspector (14 selects, 15 inputs live there). One CSS layer, no per-control hacking.

Not changing: layout/spacing, the toolbar icons, the theme tokens themselves — only the control chrome.
