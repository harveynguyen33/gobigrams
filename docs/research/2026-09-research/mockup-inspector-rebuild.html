How collapse works — and an honest note
  • Excalidraw has no accordion at all — I checked its source, nothing there. So this is our pattern, not a copy of theirs. Saying that plainly rather than pretending.
  • What Excalidraw does have is a "compact" density: the same controls behind one trigger, used on tablets. That is the idea being reused.
  • A collapsed row shows the current value (Icon · server), so you can see what it is without opening it.
  • Fold state persists per section, under the app's usual diagram-studio:… key.
  • Order = by use. Excalidraw's order is fixed and never sorts by frequency — so this ordering is our call, and I'll justify each position per shape type rather than guessing.

"Giống Excalidraw khi đang gõ" — what that actually means

I read Excalidraw's source for this. There is no floating toolbar next to the text while typing. None. What you remember as "the buttons" is this panel, which stays live while you type.

So the work is not a new toolbar — it is three behaviours:

  • The panel does not change when you start typing; it keeps showing this node's Text section.
  • Clicking a control does not kick you out of the editor — normally clicking away ends editing, so that has to be held back.
  • Duplicate / Delete hide while you type, so you cannot delete the thing you are typing into. Excalidraw does exactly this.

Also worth taking: Ctrl+Shift+< / > resizes the text without leaving the editor. Escape and clicking away both keep your text (only Undo reverts) — that is Excalidraw's contract and it is what people already expect.
