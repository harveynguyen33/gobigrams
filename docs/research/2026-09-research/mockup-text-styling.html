The overflow rule (all options)

Non-negotiable, independent of where the controls live:

1. A long word breaks. overflow-wrap:anywhere on every text row — so one long token wraps instead of running 240px out of the box.

2. Nothing paints outside. The text container gets overflow:hidden, so content is clipped at the box you actually see, at any zoom.

3. The Text node too — its long annotation currently escapes 65px below a short box.

4. A clamp is NOT the fix. Silently truncating to "CDC Sou…" would hide your own data. Wrapping + clipping keeps every character reachable.

Optional (my recommendation): a subtle "needs more room" affordance when content is clipped, so it is never silent.

My recommendation: B + the overflow fix. It adds nothing to the canvas, reuses the inspector you already have, and works on the tablet/phone tiers with no new gesture.
