# Security Policy

## Supported versions

Only the latest released version gets security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately via **GitHub security advisories**:

1. Go to <https://github.com/harveynguyen33/gobigrams/security/advisories>
2. Click **Report a vulnerability**

Please don't open a public issue for anything security-related. Include what you found, how to reproduce it, and (if possible) a board export that triggers it. You should hear back within a few days.
